Git

  • git init – инициализировать локальный Git-репозиторий в текущей папке.
  • git clone [url] – клонировать удаленный репозиторий на локальный компьютер.
  • git status – проверить текущее состояние репозитория (отслеживаемые и измененные файлы).
  • git add [file] – добавить файл или изменения в индекс (область подготовленных файлов).
  • git commit -m "сообщение" – зафиксировать изменения, создав новый коммит с описанием.
  • git push – отправить локальные коммиты в удаленный репозиторий.
  • git pull – затянуть актуальные изменения из удаленного репозитория в локальный.
